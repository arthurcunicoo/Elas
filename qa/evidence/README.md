# Evidências de execução

Esta pasta começa sem resultados físicos. Os runners geram capturas, relatórios JUnit, `run.json`, gráficos/dumps de RAM/frames e diffs visuais aqui. Os artefatos de execução não entram no código por padrão.

Usar somente contas e dados de teste autorizados. Preservar aparelho/modelo, OS, versão/build, data, escala real de fonte e revisão humana junto a cada resultado. Uma simulação ou execução em emulador não pode ser reclassificada como aparelho físico.

Preencher `qa/release-evidence.json` apenas com evidências realmente revisadas. Todos os 22 requisitos começam pendentes; o gate de publicação rejeita requisitos sem arquivo comprobatório.
